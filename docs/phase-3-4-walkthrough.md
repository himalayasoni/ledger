# Phases 3 and 4 walkthrough: People, Search, Insights, privacy, voice

All four tabs now work in Ledger β, plus voice entry and private categories with fingerprint.

## The pattern every screen follows

```
VisibleEntries ──► XxxViewModel ──► buildXxxState(entries, selection, today) ──► XxxTab(state, actions)
 (Room + privacy)    (holds what you     (pure function, unit-testable,            (stateless Compose;
                      picked: filters,    no Android)                               screenshot-tested)
                      month, open card)
```

1. **Rules live in `:core`** as plain Kotlin functions with tests:
   `People.kt`, `Search.kt`, `Insights.kt`, `Habits.kt`, `voice/VoiceParser.kt`.
2. **A `buildXxxState` function** turns entries into exactly what the screen shows, already formatted
   (`PeopleUiState.kt`, `SearchViewModel.kt`, `InsightsUiState.kt`).
3. **The ViewModel** only stores your choices (which month, which filter) and combines them with the
   live entries. It survives rotation.
4. **The screen** gets plain values and reports taps. No ViewModel inside, so Paparazzi can render it.
5. **`AppShell`** wires everything: tabs, the person page, Back, sheets and toasts.

## Privacy, in one place

`data/VisibleEntries.kt` is the only door to entries for screens. It hides private categories unless
you've unlocked them, so a new screen can't leak them by forgetting a filter.
Unlocking uses `BiometricPrompt` (`ui/account/PhoneLock.kt`): Android checks the fingerprint and only
tells Ledger yes or no. Changing which categories are private writes the web's `cfg-private` record
with a *merge*, so the web PIN fields stay as they are.

## Voice

`core/voice/VoiceParser.kt` is a line-by-line port of the web's `parseLine()`.
`spec/voice-phrases.json` holds 125 phrases with the web's own output (generated by running the web
code in Node). `VoiceContractTest` checks the Kotlin port gives the same answer for every one, so the
two apps can't drift apart. The mic uses Android's speech screen (`RecognizerIntent`): no microphone
permission, and Ledger only ever receives text.

One real bug this caught: number-to-text used `Double.toString`, which changed in Java 19. CI runs
Java 17 and Android uses the older rules, so the test failed on CI but passed locally. The fix works
out the shortest digits directly (`shortestDecimal`).

## Charts

The pace and trend charts are drawn on a Compose `Canvas` using the web's SVG coordinates
(340 × 170 "viewBox" units, scaled to the width), so they look the same. Touch input maps back
from pixels to a day or bar the same way.
